# 구글 주소록 자동 동기화 스크립트 (Google Contacts Auto Updater)

ERP 전화번호부 엑셀 파일을 자동으로 다운로드하고, 구글 공식 주소록과 동기화해주는 Google Apps Script 프로젝트입니다.

## 🚀 시작하기 전에

본 프로젝트는 구글 앱스 스크립트(Google Apps Script) 환경에서 구동됩니다. 사용 전 아래의 초기 세팅 과정을 반드시 거쳐야 정상 작동합니다.

## 🛠️ 초기 세팅 방법

### 1. 파일 복사/붙여넣기
- 구글 앱스 스크립트(Google Apps Script)에서 새 프로젝트를 생성합니다.
- 본 저장소에 있는 `Code.gs`, `AutoUpdater.gs`, `WebApp.html` 파일을 생성하고 각각 코드를 복사해서 붙여넣습니다.

### 2. 환경변수(스크립트 속성) 설정 🔒
보안을 위해 계정 정보 및 사내 서버 주소는 소스코드에 직접 입력하지 않고, **스크립트 속성**으로 관리합니다.
- 편집기 좌측 톱니바퀴 아이콘 **[프로젝트 설정]** 클릭
- 스크롤을 내려 **[스크립트 속성]** 메뉴에서 다음 3가지 속성을 추가합니다.
  - `ERP_EMAIL` : 계정 이메일
  - `ERP_PASSWORD` : 계정 비밀번호
  - `ERP_BASE_URL` : 사내 서버 API 기본 주소 (예: `https://...` 끝에 `/` 제외)
  - `ERP_SPREADSHEET_ID` : 연동할 구글 시트의 ID (스프레드시트 주소에서 `d/`와 `/edit` 사이의 문자열)

### 3. 필수 API 서비스 켜기 (매우 중요 ⭐)
구글 주소록을 제어하기 위해 반드시 **People API**를 활성화해야 합니다.
- 편집기 좌측 메뉴의 **[서비스(Services) +]** 버튼 클릭
- 목록에서 **People API**를 찾아 **추가(Add)** 합니다.

### 4. 웹 앱 배포 (UI 사용)
UI를 통해 수동 갱신을 하거나 상태를 확인하려면 웹 앱으로 배포해야 합니다.
- 우측 상단 **[배포(Deploy)] ➔ [새 배포]** 클릭
- 유형을 **'웹 앱'**으로 선택
- 실행 주체: '웹 앱에 액세스하는 사용자' (또는 '나')
- 액세스 권한: 본인 상황에 맞게 설정한 뒤 배포 버튼을 누릅니다.

### 5. 자동 동기화 트리거 설정 (선택 사항)
자동으로 갱신되길 원한다면 트리거를 설정합니다.
- 좌측 시계 모양 아이콘 **[트리거]** 메뉴 클릭
- 우측 하단 **[트리거 추가]** 클릭
- 실행할 함수: `runAutoSync`
- 이벤트 소스: **시간 기반**
- 주기를 설정(예: 매일 자정)하고 저장합니다.
